
# 🛡️ CYBERSIM | Interactive Cybersecurity Lab

An interactive, beginner-friendly cybersecurity learning lab designed to teach essential cybersecurity concepts through safe simulations, practical exercises, and knowledge checks.

## 🌐 Live Website

**[Visit CYBERSIM](https://ireogueche.github.io/simulated-cybersecurity-for-beginners/)**

## 📚 Learning Modules

| Module | Topic |
|---|---|
| 01 | Cybersecurity Basics |
| 02 | Phishing Awareness |
| 03 | Password Security |
| 04 | Social Engineering |
| 05 | Network Security |
| 06 | Malware Awareness |
| 07 | Linux Basics |
| 08 | Online Safety |

## ✨ Key Features

- Interactive cybersecurity simulations.
- Beginner-friendly quizzes and challenges.
- Practical security scenarios.
- Password strength checker.
- Basic Linux command exercises.
- Previous and Next Module navigation.
- Homepage linking all learning modules.

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 🎯 Project Objectives

- Introduce beginners to cybersecurity fundamentals.
- Improve phishing and social engineering awareness.
- Promote strong password practices.
- Explain basic network and malware security.
- Introduce essential Linux commands.
- Encourage responsible and safe internet use.

## 👥 Target Audience

- Cybersecurity beginners.
- Students interested in information security.
- Individuals developing digital safety awareness.
- Anyone interested in learning basic cybersecurity concepts.

## 🔒 Safety Notice

This project is an educational simulation.

All exercises are designed for safe learning. No real passwords or sensitive personal information should be entered into the simulations.
