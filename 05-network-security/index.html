Connecting to public Wi-Fi

You are visiting a café and want to connect to the internet using its public Wi-Fi. You notice several networks with similar names. One appears to be the café's network, while another has an unfamiliar name. Before connecting, you need to decide how to verify the correct network.

Security reminder: A familiar-looking network name does not prove that a Wi-Fi network is legitimate. Similar names can be used to mislead users.

What should you do before connecting?

Key takeaway

Public Wi-Fi can expose users to security and privacy risks, especially when networks are unfamiliar or impersonate legitimate hotspots. Confirm the correct network with staff, avoid sensitive transactions on untrusted networks, and use secure connections. A VPN can add protection, but it does not make every network or online activity automatically safe.
