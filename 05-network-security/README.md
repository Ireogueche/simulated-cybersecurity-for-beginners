# 🌐 Network Security

## What Is Network Security?

Network security means protecting computer networks from people who should not have access to them.

It helps keep devices, connections and information safe.

## Why Is It Important?

Network security helps to:

- Prevent unauthorised access.
- Protect private information.
- Keep devices safe from attacks.
- Make internet connections more secure.

## Common Network Security Risks

- **Unknown Wi-Fi:** Fake or unsafe networks can put your information at risk.
- **Unauthorised Access:** Strangers may try to connect to a network.
- **Data Theft:** Attackers may try to steal information.
- **Weak Security:** Poor passwords can make networks easier to access.

## How to Stay Safe

- Use trusted Wi-Fi networks.
- Protect your home Wi-Fi with a strong password.
- Avoid sharing sensitive information on public Wi-Fi.
- Keep your devices and software updated.
- Confirm a network's name before connecting.
