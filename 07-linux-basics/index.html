Get comfortable with Linux commands

Linux commands allow users to interact with a computer through a terminal. Explore the sample terminal below, then answer four questions to test your understanding.

LINUX TERMINAL — EXAMPLE

user@cybersim:~$ pwd

/home/user

user@cybersim:~$ ls

Documents Downloads Pictures

user@cybersim:~$ whoami

user

user@cybersim:~$ mkdir practice

Key takeaway

Linux commands provide a powerful way to interact with an operating system. Start by understanding common commands such as pwd, ls, mkdir and whoami. Practise in a safe learning environment before using commands on systems you do not own or manage.
