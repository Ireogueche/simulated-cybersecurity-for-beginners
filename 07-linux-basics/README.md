# 🐧 Linux Basics

## What Is Linux?

Linux is an operating system used on computers, servers, and networks. It is also widely used in cybersecurity.

## Why Is Linux Important in Cybersecurity?

Linux helps cybersecurity professionals manage computers, work with files, monitor networks, and use security tools.

## Basic Linux Commands

| Command | Purpose |
|---|---|
| `pwd` | Shows your current location |
| `ls` | Lists files and folders |
| `cd` | Changes directories |
| `mkdir` | Creates a folder |
| `touch` | Creates a file |
| `cat` | Displays file contents |
| `whoami` | Shows your username |
| `clear` | Clears the terminal |

## Linux Safety Tip

Be careful when using the `rm` command. It deletes files and folders, and deleted items may be difficult to recover.
