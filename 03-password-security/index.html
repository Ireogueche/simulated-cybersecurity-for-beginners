How strong is your sample password?

A strong password makes it harder for someone to gain unauthorised access to an account. Use the checker below to understand five important password strength criteria.

Security reminder: Never enter a real password or a password you use for an actual account. Use a made-up practice password only.

Password strength Not assessed

Password security checklist

✓ At least 8 characters
✓ At least one uppercase letter
✓ At least one lowercase letter
✓ At least one number
✓ At least one special character

Key takeaway

Use long, unique passwords for different accounts. A password manager can help you create and store them securely. Enable multi-factor authentication wherever possible. Meeting all five checklist criteria is a useful starting point, not a guarantee that a password is completely secure.
