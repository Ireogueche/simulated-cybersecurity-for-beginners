# 🔐 Password Security

## What Is Password Security?

Password security means protecting your accounts with passwords that are difficult for others to guess.

A strong password helps keep your personal information safe.

## What Makes a Strong Password?

- Use at least 12 characters.
- Mix uppercase and lowercase letters.
- Include numbers and symbols.
- Avoid names and easy-to-guess words.
- Never reuse the same password everywhere.

## How to Stay Safe

- Never share your passwords.
- Avoid using personal information.
- Use a different password for each account.
- Turn on two-factor authentication where available.
- Use a trusted password manager if possible.
